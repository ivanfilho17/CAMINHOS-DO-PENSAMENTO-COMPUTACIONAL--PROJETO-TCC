## ℹ️ Sobre o Projeto

Este projeto foi desenvolvido como parte do **Trabalho de Conclusão de Curso (TCC)** de **Ivan Francisco da Silva Filho** do curso de Licenciatura em Ciência da Computação pela **Universidade Federal da Paraíba (UFPB)**.

Alinhado à **Base Nacional Comum Curricular (BNCC) Computação**, a aplicação é uma ferramenta web interativa destinada a apoiar o ensino-aprendizagem dos quatro pilares do Pensamento Computacional (Decomposição, Reconhecimento de Padrões, Abstração e Algoritmos), através de uma abordagem prática, utilizando exemplos do dia a dia e atividades interativas.

---

## ✨ Funcionalidades

- **Conteúdo Didático:** Explicações teóricas integradas a exemplos reais.
- **Atividades Interativas:** Atividades de arrastar e soltar, quebra-cabeças digitais, etc.
- **Quiz com Feedback:** Exercícios de fixação com retorno imediato ao aluno.
- **Design Lúdico:** Interface colorida, atrativa, simples e intuitiva.
A aplicação está dividida em uma introdução e 4 módulos principais, cada um com teoria, atividades interativas e quiz.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas de desenvolvimento web:

- **[React](https://reactjs.org/)**: Biblioteca principal para construção da interface.
- **[Vite](https://vitejs.dev/)**: Ferramenta de build rápida.
- **[React Router DOM](https://reactrouter.com/)**: Navegação entre páginas (SPA).
- **[@dnd-kit](https://dndkit.com/)** & **[@hello-pangea/dnd](https://github.com/hello-pangea/dnd)**: Implementação das mecânicas de "Arrastar e Soltar" (Drag and Drop) acessíveis.
- **[Framer Motion](https://www.framer.com/motion/)**: Animações fluidas e transições de página.
- **[React Youtube](https://github.com/tjallingt/react-youtube)**: Integração de vídeos educativos.
- **[Vite Plugin PWA](https://vite-pwa-org.netlify.app/)**: Suporte para instalação e funcionalidades offline.
- **CSS Modules & Variáveis**: Estilização modular e tema consistente.

## 📱 Disponível como App (PWA)

Este projeto é um **Progressive Web App (PWA)**. Isso significa que ele pode ser instalado em dispositivos móveis e desktops diretamente pelo navegador, sem precisar de uma loja de aplicativos.

- **Instalação:**
  - **No Desktop:** Clique no ícone de instalação na barra de endereços do navegador (Google Chrome, Edge).
  - **No Mobile (Android/iOS):** Acesse o menu do navegador e selecione **"Adicionar à Tela Inicial"** ou **"Instalar Aplicativo"**.

## 💻 Como rodar o projeto

Pré-requisitos: Node.js instalado.

Diferente de sites estáticos simples, este projeto utiliza tecnologias modernas que requerem o Node.js instalado. Siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/ivanfilho17/CAMINHOS-DO-PENSAMENTO-COMPUTACIONAL--PROJETO-TCC.git](https://github.com/ivanfilho17/CAMINHOS-DO-PENSAMENTO-COMPUTACIONAL--PROJETO-TCC.git)

2. Instale as dependências:  
     Acesse a pasta do projeto:
     ```bash
     cd caminhos-do-pensamento-computacional
     ```
     Depois execute:
     ```bash
     npm install

4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
   O projeto estará acessível no navegador (geralmente em http://localhost:5173).
